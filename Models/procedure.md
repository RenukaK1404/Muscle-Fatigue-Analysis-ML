## Installation

Clone the repository:

```bash
git clone https://github.com/RenukaK1404/Muscle-Fatigue-Analysis-ML.git
cd muscle-fatigue-analysis-ml
```

Install required dependencies:

```bash
pip install -r requirements.txt
```

## Requirements

The project was developed using Python and standard scientific computing libraries.

### Main Libraries

```text
numpy
pandas
matplotlib
scikit-learn
scipy
jupyter
```

Install all dependencies using:

```bash
pip install -r requirements.txt
```

## How to Run

Ensure to place the dataset `rawdata.xlsx` in the same folder as the python code

```bash
python muscle_fatigue_analysis.py
```
